Design tokens

颜色、阴影、动效、圆角、间距与字体，含浅色与深色取值。

颜色

单一中性色阶服务所有表面，层级来自前景色透出多少，因此深色模式无需第二套色阶。 四个色相是中性色之外唯一的彩度来源，每个只对应一类时刻。

--ink
--quill
--muted
--faint
--hairline
--fill
--accent
--success
--warning
--danger

动效

令牌按职责命名，而非按曲线形状。动效要么解释状态变化，要么保持视图间的连续性， 要么确认一个动作；其余一切保持静止。

令牌取值用于
--easecubic-bezier(0.2, 0, 0, 1)原地变化：开关、旋转、变色
--ease-outcubic-bezier(0.23, 1, 0.32, 1)到达，或响应输入
--ease-out-expocubic-bezier(0.16, 1, 0.3, 1)连续性：视图转场
--ease-incubic-bezier(0.4, 0, 1, 1)退出
--ease-in-outcubic-bezier(0.65, 0, 0.35, 1)循环与往复
--springcubic-bezier(0.34, 1.56, 0.64, 1)唯一的过冲：确认动作
--dur-fast150ms悬停、焦点、变色
--dur-base200ms开关与小位移
--dur-slow300ms面板、入场

圆角与间距

嵌套形状保持同心：内圆角等于外圆角减去两者之间的间距。间距刻度上的值读取刻度， 刻度外的值属于视觉微调，保持为字面量。
